# Матрицы комплексных чисел на Java

Практическая работа №1 по курсу «Программирование на языке Java». 

Выполнил студент группы 25КНТ-6 Шишков Владислав.

Программа работает с матрицами комплексных чисел: складывает, перемножает и делит матрицы, транспонирует их, считает определитель и обратную матрицу. Управление идёт через консольное меню.

## Сборка и запуск

Из корня репозитория:

```
javac -d out src/*.java
java -cp out Main
```

## Меню

```
1. Ввести A
2. Ввести B
3. A + B
4. A * B
5. A / B
6. Транспонирование
7. Определитель
8. Обратная матрица
9. Показать матрицы
0. Выход
```

Пункты 3–5 используют обе матрицы. Пункты 6–8 спрашивают, к какой матрице применить операцию (латинские `A` или `B`, регистр не важен). Пока нужная матрица не введена, программа сообщает, что она не задана.

## Формат ввода

1. Число строк и число столбцов матрицы (целые числа не меньше 1).
2. По одной строке на каждую строку матрицы. Каждый элемент записывается парой чисел `re im`: действительная и мнимая части. В строке должно быть ровно `2 × (число столбцов)` чисел через пробел.

Десятичным разделителем может быть точка или запятая. Значения `NaN` и бесконечности не принимаются. Если строка введена неверно, программа запрашивает заново только эту строку.

Пример: матрица `[[1+2i, 3], [0, 4−i]]` вводится так:

```
Число строк: 2
Число столбцов: 2
Строка 1: 1 2 3 0
Строка 2: 0 0 4 -1
```

## Правила операций

- `A + B`: размеры матриц должны совпадать.
- `A * B`: число столбцов `A` равно числу строк `B`.
- `A / B` означает `A × B⁻¹`, то есть умножение на матрицу, обратную к делителю. `B` должна быть квадратной и невырожденной, а число столбцов `A` равно размеру `B`. Левое деление (`B⁻¹ × A`) не реализовано.
- Определитель и обратная матрица определены только для квадратных матриц. Обратная матрица существует, только если определитель не равен нулю.

## Структура проекта

| Файл | Назначение |
|---|---|
| `src/Complex.java` | комплексное число и операции с ним |
| `src/ComplexMatrix.java` | матрица комплексных чисел и операции над ней |
| `src/MatrixException.java` | исключение для невозможных операций над матрицами |
| `src/ConsoleMenu.java` | консольный интерфейс |
| `src/Main.java` | точка входа |

## Замечания

Вычисления ведутся в `double`, поэтому в результатах возможны небольшие погрешности (например, `1.0E-16` вместо `0`).
